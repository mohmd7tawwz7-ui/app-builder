محوّل المشاريع (app-factory)
============================

داخل هذا الملف:

1) index.html
   تطبيق المحوّل نفسه. افتحه في Spck Editor وشغّله.
   حط مفتاح GitHub في ⚙️ الإعدادات واضغط حفظ.

2) github-files/.github/workflows/build.yml
   ملف البناء اللي يكون في مستودع GitHub (app-builder).
   هذا الملف ما يشتغل داخل Spck، مكانه في GitHub فقط:
   github.com/mohmd7tawwz7-ui/app-builder/edit/main/.github/workflows/build.yml
   (إذا مستودعك فيه نفس الملف من قبل، ما تحتاج تغيّر شي)

طريقة الاستخدام:
- اختر ملف ZIP لمشروعك (لازم يكون داخله index.html)
- اكتب الاسم، واختر الأيقونة (اختياري)
- اختر APK أو موقع أو الاثنين، واضغط 🚀 حوّل
- التطبيق ينزل لك كملف ZIP: افتحه من تطبيق الملفات، فك الضغط، وثبّت ملف APK

تنبيهات:
- لا تشارك مفتاح GitHub مع أحد ولا تحطه داخل أي ملف في GitHub
- المستودع عام: لا تحط في مشاريعك كلمات سر أو معلومات خاصة
- الحد الأقصى لحجم المشروع 25MB
