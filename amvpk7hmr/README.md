# آخر أثر ٢ — THE LAST TRACE II

الجزء الثاني من «آخر أثر». تستيقظ النسخة رقم ٠٨ من آدم داخل وعاء زجاجي، ويرافقها صوت في رأسها... أثر النسخة السابعة.
لعبة ألغاز ومنصات ثنائية الأبعاد بأجواء مظلمة، مكتوبة بـ HTML5 و JavaScript لتعمل على **Spck Editor** والمتصفح و itch.io.

## التشغيل على Spck Editor
1. فك ضغط الملف `the-last-trace-2.zip`.
2. في Spck Editor: افتح المجلد `the-last-trace-2` كمشروع.
3. افتح `index.html` واضغط زر التشغيل.
4. أدر الهاتف بالوضع الأفقي، والمس الشاشة للبدء.

## التحكم
| الهاتف | لوحة المفاتيح | الوظيفة |
|---|---|---|
| ◀ ▶ | الأسهم أو A / D | الحركة |
| زر القفز | Space أو W | القفز / التسلق |
| زر الاندفاع (البرق) | Shift أو L أو X | اندفاعة سريعة — تكسر الزجاج، وتعود بعد ثانيتين |
| زر اليد | E أو J | الرافعات والحبال والأقراص والآثار |
| زر اليد (مطوّل بجانب صندوق) | E مطوّل | الإمساك بالصندوق وسحبه |
| — | S | الانحناء |
| زر ⏸ | Esc | إيقاف مؤقت |

## الجديد في الجزء الثاني
- **15 فصلًا** طويلًا مليئًا بالألغاز.
- **الاندفاع (داش)**: يُستخدم كل ثانيتين، ويلزم للقفز فوق الحفر الواسعة.
- **الحمض** بدل الماء: لمسه يعني الموت.
- **ألغاز الزجاج**: اكسر الجدران بالاندفاع، أو أسقط صندوقًا ثقيلًا على الأرضيات الزجاجية. الزجاج المقوّى بإطار معدني لا يكسره الاندفاع.
- **أقفال الرموز**: أدر الأقراص لتطابق الرموز. أحيانًا تكون الرموز مكتوبة على الجدار، وأحيانًا لا تظهر إلا بالضوء، وأحيانًا موزعة على غرف سابقة مع أرقام ترتيبها.
- **جمع القطع**: قطع مضيئة تُعاد إلى آلة لتفتح البوابة.
- **الفصل الثامن** هروب كامل من موجة حمض.
- **حوار داخلي** بين آدم والصوت في رأسه (عربي أو إنكليزي حسب لغة اللعبة).
