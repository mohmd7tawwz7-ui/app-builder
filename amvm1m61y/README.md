# آخر أثر — THE LAST TRACE

لعبة مغامرات وألغاز ثنائية الأبعاد بأجواء مظلمة سينمائية، مكتوبة بـ HTML5 و CSS3 و JavaScript (Canvas) لتعمل على **Spck Editor** والمتصفح.

## التشغيل على Spck Editor
1. فك ضغط الملف `the-last-trace.zip`.
2. في Spck Editor: افتح المجلد `the-last-trace` كمشروع (أو استورده).
3. افتح `index.html` واضغط زر التشغيل (Preview).
4. أدر الهاتف بالوضع الأفقي، والمس الشاشة للبدء.

> يمكن أيضًا فتح `index.html` مباشرة في Chrome على الكمبيوتر والتحكم بلوحة المفاتيح.

## التحكم
| الهاتف | لوحة المفاتيح | الوظيفة |
|---|---|---|
| ◀ ▶ | الأسهم أو A / D | الحركة (الجري يبدأ تلقائيًا بعد لحظة) |
| زر القفز | Space أو W | القفز / التسلق / ترك الحبل |
| زر اليد (ضغطة) | E أو J | سحب الرافعات والحبال، قراءة الآثار، طرق الجدران |
| زر اليد (مطوّل بجانب صندوق) | E مطوّل | الإمساك بالصندوق وسحبه |
| — | S | الانحناء (ويحدث تلقائيًا تحت الأسقف المنخفضة) |
| زر ⏸ | Esc | إيقاف مؤقت |

من **الإعدادات** يمكنك تغيير حجم الأزرار وشفافيتها وتحريك أماكنها بالسحب.

## الفصول (6 فصول)
1. **الغابة الميتة** — صندوق وجرف، حبل يُسقط شجرة جسرًا، صندوق ثقيل على لوح ضغط، أول مطاردة من الظل.
2. **المستنقع** — سباحة محدودة النَّفَس، تصريف حوض، صندوق طافٍ يرتفع مع الماء، كائن البحيرة الذي يُشتَّت بالصوت.
3. **المصنع المهجور** — بكرة بمنصتين، أرضية مكهربة، مكابس ساحقة، حبل متأرجح، حارس آلي (تخفَّ ثم أسقط عليه صندوقًا)، مطاردة على ممرات تنهار.
4. **الأنفاق** — ظلام شبه تام، منصات لا تظهر إلا بالضوء، جدار سري تدلّك عليه الدقات، ظهور الظل بوضوح، مناشير.
5. **المدينة الغارقة** — أسطح تنهار، قاعة تُغمر بالماء (ضغط + طوف)، حطام يسقط، مطاردة أخيرة.
6. **المنشأة السرية** — مصعد ورف وكهرباء ولوح ضغط، موزّع صناديق تكدّسها، ثم قاعة الأوعية والنهاية.

يوجد 10 «آثار» مخفية تكشف القصة تدريجيًا.

## هيكل الملفات
```
index.html        الصفحة الرئيسية (ترتيب تحميل السكربتات)
css/style.css     تصميم القوائم والأزرار
js/core.js        الثوابت وأدوات عامة (سرعة القفز، الجاذبية...)
js/i18n.js        كل النصوص بالعربية والإنجليزية
js/save.js        الحفظ في LocalStorage مع رقم إصدار لترحيل البيانات
js/audio.js       كل الأصوات مولّدة برمجيًا (لا ملفات صوت)
js/input.js       أزرار اللمس المتعدد ولوحة المفاتيح ومحرر الأماكن
js/world.js       التصادمات، الإشارات، المنصات المتحركة، نقاط الحفظ
js/player.js      حركة آدم ورسمه الهيكلي
js/entities.js    عناصر الألغاز والأعداء والمخاطر
js/levels.js      تصميم الفصول الستة (إحداثيات)
js/render.js      الخلفيات والإضاءة والضباب والجزيئات والمؤثرات
js/game.js        الحلقة الرئيسية، الموت، المشاهد السينمائية
js/ui.js          القوائم
js/main.js        نقطة البداية
manifest.json, sw.js, icon*   للتثبيت كتطبيق ويب (PWA)
```

### تعديلات سريعة
- **سرعة/قفز الشخصية**: `js/core.js` (القيم `RUN`, `JUMP`, `G`).
- **النَّفَس تحت الماء**: `STAMINA` في `js/core.js`.
- **النصوص والقصة**: `js/i18n.js`.
- **المراحل**: `js/levels.js` — `g(x1, x2, ارتفاع)` أرض، `b(x, y, w, h)` كتلة، `e('نوع', {...})` عنصر.
- **وضع الاختبار**: افتح `index.html?debug=1` ثم: N الفصل التالي، G عدم الموت، T قفزة للأمام.

## رسومات الشخصية (Sprites)
- رسومات آدم موجودة في `assets/sprites/` (20 ملف PNG، ملف لكل حركة).
- معلومات كل ملف (عدد الفريمات وحجمها) في أعلى `js/sprites.js`.
- اختيار الحركة حسب حالة آدم في الدالة `S.pick` داخل `js/sprites.js`.
- إذا حذفت الصور أو لم تُحمّل، تعود اللعبة تلقائيًا للشخصية المرسومة بالكود.
- لإيقاف السبرايت مؤقتًا: غيّر `enabled: true` إلى `false` في `js/sprites.js`.

## الأصول والتراخيص
- رسومات الشخصية من تصميم صاحب اللعبة (مولّدة بأداة صور). باقي الرسومات تُرسم بالكود على Canvas، وكل الأصوات والموسيقى تُولَّد بـ Web Audio API داخل اللعبة.
- لا خطوط خارجية ولا مكتبات. اللعبة أصلية ولا تستخدم أي عنصر من LIMBO.

## التحويل إلى تطبيق Android (APK)
ملفات HTML وحدها ليست APK. الخيارات:
1. **Capacitor** (الأفضل، يحتاج كمبيوتر + Android Studio):
   ```
   npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "The Last Trace" com.lasttrace.game --web-dir=.
   npx cap add android && npx cap open android
   ```
   ثم Build → Build APK، واضبط الاتجاه على `landscape` في `AndroidManifest.xml`.
2. **أدوات تحويل HTML/ZIP إلى APK عبر الإنترنت**: ارفع ملف الـ ZIP، واختر الوضع الأفقي وملء الشاشة.
3. **PWA**: ارفع المجلد على استضافة مجانية (GitHub Pages مثلًا)، افتحه في Chrome، ثم «إضافة إلى الشاشة الرئيسية» — يعمل كتطبيق وبدون إنترنت.

## ما لم يكتمل بعد (بصراحة)
- مدة اللعب الحالية تقريبًا **30–45 دقيقة**، وليست 3–6 ساعات؛ الفصول قصيرة ويمكن توسيعها في `levels.js`.
- الرسومات إجرائية (مرسومة بالكود) وليست لوحات مرسومة يدويًا من فنان.
- لا توجد شاشة موت مختلفة لكل سبب بشكل كامل (توجد مؤثرات مختلفة لكل سبب).
- لم يُختبر على أجهزة Android حقيقية، فقط على متصفح Chrome بمحاكاة شاشة هاتف. إذا ظهر بطء استخدم «جودة منخفضة» أو «توفير الطاقة».
